VoicemailStatus

open class VoicemailStatus

Voice-message state carried by an MWI NOTIFY (RFC 3842). Parcelable so it can ride a single broadcast extra, mirroring RtpStreamStats.

Parsing follows RFC 3842's application/simple-message-summary body:

  1. the body must be that content type (other event bodies are ignored);
  2. Messages-Waiting: yes|no is the authoritative "are there new messages" flag — it can be yes with no per-class line at all;
  3. the optional Voice-Message: new/old (urgentNew/urgentOld) line refines it with counts when present.
